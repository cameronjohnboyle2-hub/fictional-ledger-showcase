# Showcase boundary

This repository has no credentials, account service or production connection. Its hosted artifact is a static app with invented data and memory-only changes. Do not enter real records. Reload/reset removes fictional changes. Browser connections and form submissions are blocked by the content policy; there is no environment switch to reconnect a backend.

Report showcase defects through a repository issue using invented reproduction data. Never post private records, credentials or details from the original operational system. Dependency audit results are checkpoints, not a guarantee of complete security. The original application is outside this release's security boundary.
